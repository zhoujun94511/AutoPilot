# 工程模型 · 新建/修改规则

## 1. 层级与文件

「工程」= 一个目录(无强制清单文件)。打开工程 = 把该目录设为工作区；工程树以**工程目录本身为根节点**，其内容挂在下面（不暴露上层路径/同级目录）。

工程目录下的资源（都是文件，可放任意层子目录组织）：

| 资源     | 文件后缀          | 编辑器                 | 内容                                  |
|--------|---------------|---------------------|-------------------------------------|
| 用例     | `.tc.yaml`    | CaseEditor          | before/case/after/fault 四段步骤 + 数据驱动 |
| 测试套    | `.ts.yaml`    | SuiteEditor         | 成员用例(引用) + before/after/fault       |
| 测试计划   | `.tp.yaml`    | TestPlanEditor      | 成员(用例/套件)相对路径引用                     |
| 对象库    | `.map.yaml`   | MapEditor           | 定位符元素库（工程级共享）                       |
| 数据配置   | `.properties` | DataConfigEditor    | 键值配置（工程级共享）                         |
| 自定义关键字 | `.ks.yaml`    | CustomKeywordEditor | 局部参数 + 步骤序列                         |

新建工程时**自动**生成骨架 `config/DataConfig.properties`(空模板)；其余资源按需手动新建。

## 2. 在哪一层能「新建」什么

新建分两个入口，行为不同（对标成熟 IDE：File>New = 未命名草稿；树右键 = 在文件夹内建文件）：

| 入口                           | 行为                    | 约束               |
|------------------------------|-----------------------|------------------|
| 文件 ▸ 新建工程… / 打开工程            | 选/建目录设为工作区            | 任何时候可用           |
| 文件菜单 / 工具栏「快速草稿用例」「新建自定义关键字」 | 打开**未命名草稿**编辑器，保存时选位置 | 任何时候可用           |
| **工程树头部 `＋` / 右键 ▸ 新建**      | 在**目标目录**直接建文件并打开     | **必须已打开工程**，否则禁用 |

**右键「新建」的目标目录**（`_target_dir`）：
- 选中**目录** → 建在该目录内；
- 选中**文件** → 建在该文件**所在目录**（同级，不会"建进文件里"）；
- 未选中 → 建在**工程根**；
- **无工程** → 整个「新建」子菜单禁用，且任何落文件的新建都被 `_require_project` 拦截（绝不写入当前工作目录）。

可在右键「新建」里建：用例 / 测试套 / 对象库 / 数据配置 / 测试计划 / 自定义关键字 / 子文件夹。

## 3. 各资源能「修改」什么（编辑器各管各的，不越界）

| 资源       | 可修改                          |
|----------|------------------------------|
| 用例       | 步骤增删改/排序、条件/循环、步骤参数、说明、标签    |
| 测试套      | 成员用例增删/排序、before/after/fault |
| 测试计划     | 成员(用例/套件)增删/排序               |
| 对象库      | 元素名称/定位符增删改                  |
| 数据配置     | 键值对增删改                       |
| 自定义关键字   | 局部参数 + 步骤序列                  |
| 文件夹 / 工程 | 无"内容"可改；仅重命名/删除              |

## 4. 重命名 / 删除

- 对工程树中**选中的文件或文件夹**生效（未选中则禁用）。
- 删除走系统回收/物理删除前会确认；重命名保持后缀语义（如 `.tc.yaml`）。

## 5. 工程浏览器交互（对标 VSCode/PyCharm/Eclipse）

- **头部工具条**(VSCode Explorer)：在工程中新建▾ / 新建文件夹 / 刷新 / 折叠 / **全选** / **清空勾选** / **批量运行(N)**；无工程时新建类与全选禁用。
- **工程根节点**(PyCharm/Eclipse)：以工程目录名为唯一根，内容挂其下，不暴露上层路径/同级目录。
- **文件类型图标**：用例/套件/对象库/数据配置/计划/关键字/文件夹各异，一眼区分。
- **键盘**：`Enter`/双击 打开、`F2` 重命名、`Delete` 删除。
- **右键**：新建(子菜单，标题示目标目录) / 重命名 / 删除 / 复制路径 / 刷新 / 在资源管理器中显示。
- **打开最近工程**：文件菜单动态子菜单(最近列表，去重限长)，可一键切换或清除。
- **名称过滤框**：按名称实时过滤；打开工程即预取整棵子树，故嵌套目录里的文件也能被过滤命中，命中文件的父目录/工程根递归保留。
- **去后缀显示**：`启动应用.tc.yaml` 显示为 `启动应用`（类型由图标表达），完整名见悬停。
- **复选框选用例 → 批量运行**(对标参考实现的 TestCase Explorer getChecked)：用例(`.tc`)行带复选框，勾选一批后头部「批量运行(N)」按钮亮起，一键作为一批异步执行并出 HTML 报告；勾**目录**=勾其下全部用例，目录显示三态(全选/部分/未选)；套件/对象库/配置等非用例行无复选框。
