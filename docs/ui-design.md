# 前端信息架构与交互设计

本文记录 AutoPilot IDE 的界面信息架构（IA）：对标成熟关键字驱动测试 IDE（Eclipse-RCP「Automation」透视图）整理，目标是**动作有归属、面板按用途分组、命令收敛到单一事实源**，而非散落各处。

## 1. 设计原则

- **单一事实源**：所有命令在 `autopilot/ui/actions.py` 声明一次（id/文案/槽/作用域/快捷键/图标），菜单栏、工具栏、编辑器右键统一从此构建。新增功能 = 注册一个动作。
- **作用域分层**：
  - `global`（文件/运行/设备）→ 主菜单 + 主工具栏；
  - `editor`（步骤增删改、控制流插入、剪贴板）→ 编辑器右键 + 编辑菜单，**不进全局工具栏**，转发给当前用例/套件编辑器。
- **面板按用途分组**：相关面板 Tab 同区，减少视觉层级混淆。
- **文案规范**：动词开头、句首式中文短语；图标走 qtawesome（mdi6），不混入 emoji。

### 新建双轨（保留，用文案区分）

| 入口                        | 行为                   | 何时用       |
|---------------------------|----------------------|-----------|
| 工具栏「快速草稿用例」               | 内存编辑，保存时再落盘；**可无工程** | 快速上手、先写后存 |
| 工程区 `＋` 下拉 / 文件菜单「新建▸用例…」 | 在工程内命名并**立即落盘**      | 正规工程内建资源  |

### 运行语义（避免同名）

| 入口                  | 含义                  |
|---------------------|---------------------|
| 编辑器标签栏「运行」(F5)      | 跑当前编辑器中的完整用例        |
| 菜单 / 右键「运行当前步骤」(F6) | 只跑编辑器中选中的一步         |
| 工程区「批量运行(N)」        | 跑工程树中勾选的多个 `.tc` 用例 |

## 2. 信息架构

### 菜单栏

| 菜单 | 内容                                                               |
|----|------------------------------------------------------------------|
| 文件 | 打开工程/文件 · 新建▸(用例/测试套/对象库/数据配置/测试计划/自定义关键字/文件夹) · 保存/另存为 · 重命名/删除 |
| 编辑 | 撤销/重做 · 复制/剪切/粘贴步骤 · 删除/上移/下移 · 插入控制流▸(if/if-else/循环/移动循环)       |
| 运行 | 运行用例(F5) / 运行当前步骤(F6) / 运行测试套 · 暂停 / 停止 · 计划执行                   |
| 设备 | 已连接设备… · 查看安装包信息…                                                |
| 视图 | 各面板显隐（dock 自带 toggle）· 重置布局                                      |
| 帮助 | 关于                                                               |

> **设备能力分层（勿再开独立「设备窗」、勿在顶层重复挂动作）**  
> - **菜单「设备」**：仅两项——**已连接设备…**（枢纽：每台真机 → 设检视 / 看信息 / **开始实时镜像**）· **查看安装包信息…**（本地 APK/IPA，与是否连机无关）  
> - **Web 检视**：控件检视器「刷新快照」先选平台（含 Web），不再从设备枢纽进入  
> - **状态栏 Chip**：摘要 + 点击弹出与「已连接设备…」相同的枢纽菜单  
> - **右侧「设备区」**：控件检视器 / 实时镜像（会话工具，不是 Device Manager）  
> - **勿重复**：真机「设为检视目标」已覆盖连接检视；勿再在枢纽底部挂「连接检视设备…」

### 全局工具栏

**已移除顶栏工具条。** 动作按归属分散：

| 区域             | 按钮               | 含义                 |
|----------------|------------------|--------------------|
| **工程区工具条**（右端） | 保存 · 批量运行        | 落盘当前文档；跑工程树勾选的多个用例 |
| **编辑器标签栏右侧**   | 运行(F5) · 暂停 · 停止 | 跑/控当前打开文档中的用例      |
| **文件菜单**       | 快速草稿用例 等         | 无工程时新建、低频文件操作      |

> 已连接设备 / 设检视 / 实时镜像 / Web 检视见状态栏 Chip 或「设备 → 已连接设备…」。运行测试套 / 计划执行 / 失败策略在菜单或状态栏。

### 编辑器右键菜单（editor 作用域）

`删除/上移/下移 ‖ 插入 if/if-else/循环/移动循环 ‖ 复制/剪切/粘贴步骤`

### 面板布局（dock 分组）

| 区域    | 面板                                 | 容器                                                                        |
|-------|------------------------------------|---------------------------------------------------------------------------|
| 左     | 侧栏（工程树 + 文件名筛选）                    | 单个 Dock                                                                   |
| **右** | **编辑**：关键字库 / 参数 · **设备**：检视器 / 镜像 | **单个 Dock「右侧辅区」**，内嵌上下 `QSplitter` + 两组 `QTabWidget`（Tab 只切换视图，不浮动/不误关单页） |
| 中     | 编辑器堆叠                              | 中央区                                                                       |
| 底     | 执行控制台                              | Dock                                                                      |

右侧交互要点：
- **✕** 仅隐藏整条「右侧辅区」（视图菜单 / `Ctrl+Alt+R` 可恢复）
- **编辑参数** 只切上区「参数」Tab，**不抢**下区当前检视/镜像页
- 分割条可调上下比例；工具条可「扩展设备区」
- 窗口布局与分割比例 **跨会话记忆**（`settings.json`）

### 状态栏

左侧：失败策略、iOS 后端（仅 iOS 工程显示）。右侧：**运行进度**（多用时例显示 `用例 v/m`，单用例为不确定进度）、**设备 Chip**、暂停指示。

窗口标题固定为 **AutoPilot**（工程上下文由侧栏工程树与编辑器标签承载，不进标题栏）。

## 3. 对标来源

参考工程（`referencedata`）的 Eclipse-RCP「Automation」透视图：左 TestCase Explorer、右 Keyword/UserDefine/Network 视图、中部多标签编辑器、底部 Log/Search/DataConfig，菜单 File/Edit/Run/Search/View/Window/Help，工具栏分 runGroup 等组。本设计取其「左导航·中编辑·右关键字·底诊断」骨架与动作分组思路，落到 PyQt6 的 QMainWindow + QDockWidget。

## 4. 实现落点

- `autopilot/ui/actions.py` — 动作注册表 + 菜单/工具栏/右键结构声明。
- `autopilot/ui/widgets/chrome/` — 可复用 chrome（状态栏、主工具栏、菜单栏、工程工具条、右侧辅区 Tab 等）。
- `autopilot/ui/theme/` — 集中 QSS（`apply_main_window`、`panel_stylesheet`、`apply_dialog_theme`）；**默认「跟随系统」**，监听 macOS 自动浅色/深色切换；也可在视图菜单固定浅色/暗色。全局壳层（Dock、树、标签栏、控制台等）与面板 QSS 一并刷新。
- 主题回归：`.venv/bin/python skills/autopilot-lint/check_ui_theme.py`（已接入 `autocheck.py` 硬失败）。
- `autopilot/ui/widgets/left_sidebar.py` — 左侧侧栏：直挂 `ProjectPanel`（工程工具条 + 文件名筛选 + 工程树）。
- `autopilot/ui/widgets/project_panel.py` — 工程浏览器面板（筛选框替代独立搜索页）。
- 测试：`tests/test_ui_structure.py`（注册表完整性 + 菜单/工具栏作用域隔离 + Dock 分组 + 右键菜单）。

## 5. 日志规范

### 5.1 后端骨干（`autopilot/runtime/log.py`）

标准 `logging`：`get_logger("模块")` → `autopilot.模块` 子 logger；`setup_logging()` 装「轮转文件 + stderr」，`run_log(name)` 为单次执行另落 `logs/runs/<时间>_<名>.log`。GUI 经 `ui/log_bridge.QtConsoleHandler` 桥接（线程安全），带 `extra={"ap_no_gui": True}` 的记录只落文件、不在控制台重复。

### 5.1.1 分层原则（前端 = 业务视图）

**控制台只显示业务相关日志，开发/调试细节留 terminal + 文件。** 各出口阈值：

| 出口                          | 阈值       | 内容                          |
|-----------------------------|----------|-----------------------------|
| 文件 `logs/`（轮转 + 每-run）      | DEBUG    | 全量，含 DEBUG 开发细节，供事后回溯       |
| terminal（stderr）            | INFO     | 运行期粗粒度                      |
| GUI 控制台（`QtConsoleHandler`） | **INFO** | 业务事件 / 警告 / 错误；**DEBUG 不进** |

- **业务事件**（用户该看见：执行进度、保存、设备连接、失败原因）→ `console.log(...)` 或 `get_logger(x).info/warning/error(...)`。
- **开发细节**（帧解析、字节报文、HTTP 重试、内部状态）→ `get_logger(x).debug(...)`：进文件/terminal，不刷控制台。
- 控制台「调试」开关临时把桥接 handler 降到 DEBUG，排查时把开发细节拉进 GUI（文件始终全量，不受开关影响）。

### 5.2 控制台列

时间 ｜ 级别 ｜ 状态 ｜ 来源 ｜ 说明 ｜ 信息。**级别**(DEBUG/INFO/WARNING/ERROR，各自颜色)与**状态**(PASS/FAIL/NOIMPL/SKIP，执行结果专用)分列、互不混；纯日志行状态列留空。支持状态过滤、级别阈值过滤、文本过滤、自动滚动开关、暂停（缓冲回放）。

### 5.3 前端日志写法（`console.log(message, source, level)`）

- **source（来源/分类）**：`运行`/`计划`/`结果`/`报告`/`文件`/`工程`/`编辑`/`设备`/`检视`/`镜像`。落「来源」列，便于分类与扫读，不再把分类写进正文。
- **level**：进行/完成→`INFO`；前置条件未满足、提示、可恢复异常→`WARNING`；失败/不可用/异常→`ERROR`。
- **文案**：
  - 全角冒号 `：` 引出详情；列举用顿号 `、`；路径/值用全角括号 `（…）` 包裹。
  - 不加前导 `\n`、不用装饰线 `=====`、不用感叹号与口语（如「请知」）。
  - 完成态用「已X：详情」；前置条件用「请先X」；失败用「X失败：原因」；进行中用「正在X…」。
- 示例：`已保存用例：a.tc`（文件/INFO）、`请先选中一个步骤`（运行/WARNING）、`Appium 不可用：<原因>`（检视/ERROR）。

## 6. 关键字库 / 用例编辑器交互（对标 IDE）

- **关键字库面板**(对标 VSCode 命令面板)：顶部搜索框按 名称/ID/说明 实时过滤，命中自动展开并保留所属分组、清空恢复；分栏(关键字/ID/说明)、平台不支持项灰显+悬停原因、拖拽/双击/右键插入。
- **用例编辑器**(对标序列编辑器)：键盘 `Delete` 删除步骤、`Ctrl+↑/↓` 上移/下移、`Ctrl+D` 复制行(单元格编辑态不触发)；另有右键菜单与撤销/重做。
- **关键字列显示一致**(对标参考实现的 `getName`)：步骤「关键字」列显示**中文关键字名**（由目录按 id 解析，与关键字库左列一致），原始 id 落到**悬停提示**——id/参数名/逻辑一律不改，仅展示层用中文；新建步骤「说明」列默认填关键字**描述**(comment)而非名字，避免两列重复。自定义关键字(.ks)无目录名则回退显示其 id。
